# Проверка сайта на упоминания иноагентов и запрещённых организаций

Скрипты проверяют текстовую часть сайта на упоминания сущностей из официальных реестров Минюста РФ:

- **Реестр иностранных агентов** — https://minjust.gov.ru/ru/pages/reestr-inostryannykh-agentov/
- **Федеральный список экстремистских материалов** — https://minjust.gov.ru/ru/extremist-materials/
- **Перечень экстремистских организаций** (бонусом)
- **Перечень нежелательных организаций** (бонусом)

Результат — Excel-отчёт со ссылками на конкретные страницы и контекстом каждой находки.

Пайплайн отработан на сайте https://history.ru (7 778 страниц разделов «Статьи», «Памятники», «События», «Биографии», «Исследования»).

## Как это работает

1. **`fetch_registries.py`** — выгружает три реестра (иноагенты, экстремистские и нежелательные организации) через REST API `reestrs.minjust.gov.ru`.
2. **`fetch_extremist_materials.py`** — скачивает федеральный список экстремистских материалов (пагинированные страницы Минюста, ~5 500 записей).
3. **`fetch_history.py`** — выгружает тексты страниц сайта из sitemap.xml по нужным разделам (параллельно, 8 потоков). Под каждый другой сайт может потребоваться небольшая адаптация (есть универсальный `fetch_site.py`).
4. **`checker.py`** — ищет упоминания реестровых сущностей в текстах страниц.
5. **`registries_export.py`** — собирает все реестры в один `registries.xlsx` (каждый реестр на отдельной вкладке).
6. **`make_report.py`** — собирает итоговый `matches.xlsx`: сводка, совпадения со ссылками, список проверенных страниц.

## Логика поиска (`checker.py`)

- Нормализация текста (регистр, ё→е, пунктуация) + лёгкий русский стемминг — ловит склонения: «Национал-большевистскую партию» находится так же, как «Национал-большевистская партия».
- ФИО физических лиц ищутся во всех формах: «Иванов Иван Иванович», «Иванов И. И.», «И. И. Иванов», «Иван Иванов». Тип физлица берётся из колонки «Тип» реестра иноагентов.
- Организации ищутся по полному официальному названию и по краткому названию в кавычках («Фонд борьбы с коррупцией» найдётся внутри полного названия).
- Антишум:
  - однословные алиасы («Гроза», «Бумага», «Возрождение») допускаются только если слово встречается ≤ 5 раз по всему корпусу страниц;
  - названия-«филиалы» вида «Свидетели Иеговы «Нижний Тагил»» не матчатся с упоминаниями города;
  - фрагменты из служебных слов («под названием», «а именно») отбрасываются;
  - распространённые фамилии (инициалы) помечаются в отчёте жёлтым как «возможные», а не точные.

## Запуск

```bash
pip install requests lxml openpyxl

# 1. реестры
python -X utf8 fetch_registries.py
python -X utf8 fetch_extremist_materials.py

# 2. тексты сайта (укажите свой набор разделов в SECTIONS внутри скрипта)
python -X utf8 fetch_history.py

# 3. поиск упоминаний
python -X utf8 checker.py

# 4. отчёты
python -X utf8 make_report.py          # matches.xlsx — совпадения на страницах
python -X utf8 registries_export.py    # registries.xlsx — сами реестры
```

Структура файлов после прогона:

```
registries/*.json         — скачанные реестры
site_text/pages.json      — тексты страниц сайта
matches_raw.json          — сырые совпадения
dropped_aliases.json      — отфильтрованные варианты названий
matches.xlsx              — ИТОГОВЫЙ ОТЧЁТ
registries.xlsx           — реестры в Excel
```

## Замечания

- Минюст использует российский корневой УЦ — в скриптах отключена проверка SSL-сертификатов для его доменов (публичные read-only API).
- Проверяется текст страниц; текст внутри картинок и PDF-вложений не анализируется.
- Совпадение названия запрещённого материала на историческом сайте чаще всего означает исторический термин («Коктейль Молотова», «Василий Тёркин»), а не цитирование запрещённого контента — такие находки вынесены на отдельный лист отчёта для ручной оценки.
